# Scientific methods

All authoritative measurements and statistical results are produced by deterministic, versioned code against a frozen snapshot. LLMs may propose analyses but may not calculate or alter authoritative results.

Every genome-wide result must report raw p-value, multiple-testing-adjusted q-value, effect size, confidence interval, eligible sample count, and missingness. Benjamini–Hochberg FDR is the baseline unless a versioned method specification requires another correction.
