# Scientific methods

Current deterministic primitives include Benjamini–Hochberg correction, frequencies,
expression outliers/variance, CNV-expression and mutation-expression associations,
plus basic survival helpers. They are not a complete registered production engine
suite, and the durable artifact worker is not connected in restored main.

Scientific methods must declare population, eligibility, tested universe, estimand,
effect, uncertainty, multiplicity, missingness, QC, coverage, method version, and
failure behavior. Duplicate biological keys fail; unexamined or unavailable data is
never encoded as negative. R00 repairs current correctness/identity defects; R08–R12
deliver the versioned deterministic engine and search program.
