# CJ-R31 — Convergence and adaptive reasoning allocation

**Status:** planned. **Owner:** convergence policy. **Depends on:** R21–R23, R29–R30.

## Mission

Compare independent submissions, expose disagreement, and spend additional reasoning
only when evidence and expected value justify it.

## Implementation

Normalize validated Claims, map support/contradiction, measure evidence overlap and
agent dependence, identify unresolved questions, and produce a versioned convergence
record. Policy may stop, request critique, add a diverse replica, or propose a bounded
ResearchAction within budgets. Agreement is not a scientific status transition.

## Open-data rule

Multiple agents agreeing about unavailable, controlled, missing, or unexamined data
does not create evidence. Aggregation preserves access, coverage, and lineage limits;
follow-up remains within the R23 action registry.

## Tests and acceptance

Duplicate/correlated submissions, majority error, contradiction, evidence overlap,
regional scope, unavailable data, stale generations, budgets, and deterministic
policy replay pass. Every allocation decision is explainable and bounded.
