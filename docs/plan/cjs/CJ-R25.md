# CJ-R25 — Native full-loop acceptance

**Status:** planned milestone gate. **Owner:** end-to-end acceptance harness.
**Depends on:** R01–R24.

## Mission

Prove that the native application completes an auditable public-data research loop
before any external contributor transport exists.

## Positive journey

Freeze an explicitly open public fixture; minimally acquire/materialize it; partition
discovery/validation; run deterministic search; create CandidateState; obtain bounded
Jev evaluation; schedule a deterministic expansion; publish/reproduce a Finding;
build Claims/Evidence/ResearchState; issue a WorkUnit to the native agent; validate its
Submission; lock a hypothesis; run hidden validation; update state; export handoff.

## Open-data and negative journeys

Use public fixtures only. Prove controlled/missing access, token fields, auth headers,
full BAMs, whole chromosome/open-ended/oversized slices, corrupt bytes, stale workers,
Jev/agent failures, validation leakage, fabricated citations/coverage, and regional
overclaims all fail before forbidden work or scientific publication.

## Acceptance

The positive run is reproducible with exact ledgers and no manual database repair;
crash/replay publishes once; access and coverage labels survive every boundary; all
negative scenarios have stable terminal states. External APIs remain disabled and
Milestone C is not complete without this gate.
